# React To-Do App

A clean, hyper-minimalist task management application built with React, HTML, and CSS.

## Features

- **Add Tasks:** Type a task and hit `Enter` or click the Add button.
- **Toggle Completion:** Mark tasks as done with a single click on the checkbox.
- **Delete Tasks:** Remove unwanted items from your list.
- **Hyper-Minimalist UI:** Distractor-free layout inspired by modern workspace tools like Notion.
